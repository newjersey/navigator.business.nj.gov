heading-2: Code and Reuse
main-text-2: |-
  The site is a [Next.js](https://nextjs.org/) app built with the App Router. Our guidance pages come from Markdown files. You can find those files in [our repository](https://github.com/newjersey/navigator.business.nj.gov/tree/main/content/src). It does not use any closed website builder or hosted design tool. You can run your own copy.

  Want to run the site yourself? Follow the setup steps in the [README for the static site package in our code repository](https://github.com/newjersey/navigator.business.nj.gov/blob/main/packages/static-site/README.md).

  To reuse or build on our work, you can:

  * Fork or clone the repository
  * Adapt our open content and code for your own group or project
  * Open an issue or pull request so others can benefit too

  If you help build this site, please follow our [contributing guide](https://github.com/newjersey/navigator.business.nj.gov/blob/main/CONTRIBUTING.MD). Also follow our [code of conduct](https://github.com/newjersey/navigator.business.nj.gov/blob/main/CODE_OF_CONDUCT.md) and [security policy](https://github.com/newjersey/navigator.business.nj.gov/blob/main/SECURITY.md).
heading-3: History and Credit
main-text-3: |-
  Business.NJ.gov builds on work from [San Francisco](https://businessportal.sfgov.org/) and [Los Angeles](https://business.lacity.org/). Their partners, [Tomorrow Partners](https://tomorrowpartners.com/) and [CivicActions](https://civicactions.com/), built the first Business Portal. That work gave us our starting point.

  We based our design and content on the Los Angeles Business Portal. If you reuse that material, follow its license terms. You can find its open code, history, and license on the [Startup in a Day GitHub page](https://github.com/StartupInADay/Los-Angeles-California#the-business-portal).

  We've rebuilt this site more than once. An early version ran on Drupal. We no longer maintain it, but it's still available in the [business-website repository](https://github.com/newjersey/business-website). The next version ran on Webflow. Its content became the content on this site today. This site no longer depends on either one. All current code and content live in the [navigator.business.nj.gov repository](https://github.com/newjersey/navigator.business.nj.gov).
