## Eligibility

* The project is a partnership between a developer and a participating hospital
* The hospital contributes funding to the project
* The project meets all HMFA Multifamily Underwriting Guidelines and Financing Policy requirements
* The project sets aside some units for people who often need hospital care and stable housing

:::largeCallout{ showHeader="true" headerText="Benefits" calloutType="conditional" amountIconText="" filingTypeIconText="" frequencyIconText="" phoneIconText="" phoneIconLabel="" emailIconText="" }

The program combines hospital funding with HMFA loans and 4% Low-Income Housing Tax Credits. Projects can receive up to $4 million per project as a cash flow loan payable at the end of the mortgage term. Requests over $4 million will be considered case-by-case and require HMFA board approval.

:::
