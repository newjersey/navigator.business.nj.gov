## Eligibility

* The property is in 1 of these counties hit hardest by Hurricane Ida: Bergen, Essex, Gloucester, Hudson, Hunterdon, Mercer, Middlesex, Morris, Passaic, Somerset, Union, or Warren
* The project repairs an existing building. New construction does not qualify
* The property already has NJHMFA financing (Performance Based Contract Administration properties do not qualify)
* The property is in good standing with NJHMFA Asset Management
* The application explains why the project needs the proposed repairs
* The application includes a project plan and a detailed scope of work

:::largeCallout{ showHeader="true" headerText="Benefits" calloutType="conditional" amountIconText="" filingTypeIconText="" frequencyIconText="" phoneIconText="" phoneIconLabel="" emailIconText="" }

RMHP offers loans with a 0% interest rate. NJHMFA forgives 20% of the original loan amount if the project stays in compliance with program requirements. Eligible properties can receive up to $3.5 million per project, depending on available funds. There is no per-unit cap.

:::
